Если нет файла config.yml то запустите "HTML_run.exe" и он создаст его!
Откройте файл config.yml и измените параметр «file-to-load» на нужный вам путь!
Файлы HTML и подкаталоги должны лежать в каталоге, где находится «HTML_run.exe»!
